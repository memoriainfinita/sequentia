# sequentia guide

How to use sequentia for what you want to do with it. Each page is a short walk through; the [README](../../README.md) says what the app is and is not.

| I want to… | Page |
|---|---|
| Turn images into a video and export it | [Getting started](getting-started.md) |

The interface mixes English and Spanish; this guide uses the labels exactly as they appear on screen. Your images are read locally and nothing is uploaded.
